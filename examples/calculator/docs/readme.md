# 電卓サンプル (Calculator Example)

「電卓アプリ」は、入力（数値、演算子）と出力（計算結果）の関係が極めてシンプルかつ明確であるため、**PROBE の「トレース（Trace）機能」や「シャドウ実行（Shadow）機能」を直感的に理解するサンプルとして完璧な題材**です。

ご提案いただいた電卓のサンプルプログラムを `examples/calculator` ディレクトリに作成し、動作確認まで完了いたしました！

---

### 作成したサンプルコードの構成

#### 1. 各演算コンポーネント: `examples/calculator/components.py`

新旧（改善版）のロジックを比較（シャドウ実行）できるよう、**現行版（v1）**と**改善版（v2）**の2つの実装を用意しました。

- 例として、現行の `divide`（割り算）はゼロ除算時にエラー（`ValueError`）を吐きますが、改善版の `divide_v2` では安全に無限大（`inf`）を返すという、設計変更の差分を持たせています。

#### 2. メイン実行スクリプト: `examples/calculator/main.py`

`probe-agent` ライブラリの `@probe` デコレータと `set_candidate`（新候補の登録）を使用しています。

- **自動デモ実行モード**（デフォルト）
- **対話型実行モード**（`--interactive` フラグを付けることで、コンソールから数式を直接入力可能）

---

### 動かし方と解説

まずは、以下のコマンドで動作を確認できます。

#### A. 自動デモモードでの実行

```powershell
cd examples/calculator
python main.py
```

**実行出力結果:**

```text
--- デモ実行 (Automated Mode) ---
実行中: 10.0 + 5.0
 -> 結果: 15.0

実行中: 20.0 - 8.0
 -> 結果: 12.0

実行中: 6.0 * 7.0
 -> 結果: 42.0

実行中: 100.0 / 4.0
 -> 結果: 25.0

実行中: 5.0 / 0.0
 -> エラー (期待通り): Division by zero
```

#### B. 対話モードでの実行

```powershell
python main.py --interactive
```

コンソールに以下のように入力して、自由な四則演算を実行できます：

```text
--- 電卓アプリ (Interactive Mode) ---
各演算を実行すると、裏で PROBE のトレースが行われます。
終了するには 'exit' を入力してください。

式を入力してください (例: 5 + 3, 10 / 2) -> 8 * 9
結果: 72.0
```

---

### 💡 この電卓サンプルで「PROBEの魅力」がわかるポイント

1. **関数呼び出しのトレース（Trace Mode）**

   - `@probe` デコレータを付与しているため、ユーザーが電卓で `5 * 3` などを実行した際、「引数 `(a=5, b=3)` に対して、戻り値 `15` が得られた」というログが自動的に PROBE サーバーへ送信されます。

2. **シャドウ実行による安全な比較（Shadow Mode）**

   - 管理画面（Dashboard）から `calculator_add` などのモードを `shadow` に切り替えると、本番のユーザーには現行（V1）の出力結果を見せつつ、裏で**自動的に V2 実装（`add_v2`など）を同時に並行走らせ、実行結果に乖離がないかを比較検証**できます。

   - 特におすすめなのは **`divide`（ゼロ除算）の比較** です。

     - 入力 `5.0 / 0.0` に対して、
     - 現行（V1）は `Division by zero` という例外（Exception）で終了します。
     - 新候補（V2）は `inf`（無限大）を返します。
     - この状態で `shadow` 実行を走らせると、PROBE の管理画面側で「**V1はエラーを投げたが、V2は正常に終了して `inf` を返した**」という挙動の差異（diff）がビジュアルとして非常に綺麗に浮かび上がり、リファクタリングが安全に成功したか、あるいは期待通りの挙動修正がなされたかを一目で確認できます。
